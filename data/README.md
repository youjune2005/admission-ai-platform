# 데이터 폴더

이 폴더에 입시행정 관련 참고 데이터를 넣어주세요. 예:

- `guidelines/` — 모집요강, 전형 규정 등 PDF/문서
- `historical/` — 과거 입학 데이터 (CSV/Excel), 지원자 통계
- `faq/` — 자주 묻는 질문과 답변

현재는 각 기능 화면(데이터 분석, 서류 검토)에서 파일을 직접 업로드해 분석/요약할 수 있습니다.
이후 이 폴더의 데이터를 벡터 DB에 임베딩해 AI 상담 챗봇이 실제 규정을 참고해 답변하도록
RAG(검색 증강 생성) 파이프라인으로 확장할 수 있습니다.

민감한 개인정보(주민등록번호, 연락처 등)가 포함된 원본 데이터는 가급적 비식별화 후 넣어주세요.
