# 등록금 명세서 작성 양식 및 RAG 사용 지침

## 문서 정체성

- 문서명: 등록금 명세서
- 근거 양식: `[별지 제8호 서식]`
- 원본 파일: `등록금 명세서_별지 제8호 서식.pdf`
- 금액 단위: 천원 또는 원
- 용도: AI가 등록금 명세서를 작성하거나 초안을 만들 때 반드시 따라야 하는 기준 양식

## 작성 시 필수 규칙

1. 등록금 명세서 작성 요청에는 이 양식의 열 순서와 명칭을 유지한다.
2. 사용자가 제공하지 않은 학교, 학생 수, 금액은 추측하지 않고 `{입력 필요}`로 표시한다.
3. 금액 단위를 문서 상단에 명시하고 한 문서 안에서는 동일한 단위를 사용한다.
4. 입학금과 수업료는 각각 `1인당 금액`과 `금액`을 구분한다.
5. 원본 양식의 소계, 합계, 총계 행을 유지한다.
6. 계산 가능한 경우 다음 검산식을 적용한다.
   - 입학금 금액 = 학생수 × 입학금 1인당 금액
   - 수업료 금액 = 학생수 × 수업료 1인당 금액
   - 합계 = 입학금 금액 + 수업료 금액
7. 실제 제출 문서를 만들 때는 원본 PDF의 시각적 배치와 병합 셀을 최종 기준으로 삼는다.
